3. GUÍA PASO A PASO: CONECTAR LA API DE GITHUB A TU PORTAFOLIO
--------------------------------------------------------------------------------

URL del perfil: https://victorrios2010s15-cmyk.github.io/portafolio/
Usuario GitHub: victorrios2010s15-cmyk

PASO 1: En tu index.html
--------------------------------------------------------------------------------
Agrega este bloque en la sección donde quieras ver tus datos de GitHub:

<div class="github-card">
  <img id="github-avatar" src="" alt="Foto de GitHub" style="width: 80px; border-radius: 50%; display: none;">
  <h3>Repositorios Públicos: <span id="github-repos">Cargando...</span></h3>
  <p>Seguidores: <span id="github-followers">...</span></p>
</div>

Y al final del archivo, justo antes de la etiqueta </body>, agrega:
<script src="script.js"></script>


PASO 2: Crear el archivo script.js
--------------------------------------------------------------------------------
Crea un archivo llamado script.js en la misma carpeta del index.html y pega:

const urlApi = 'https://api.github.com/users/victorrios2010s15-cmyk';

async function cargarDatosGitHub() {
  try {
    const respuesta = await fetch(urlApi);
    const datos = await respuesta.json();
    
    document.getElementById('github-repos').textContent = datos.public_repos;
    document.getElementById('github-followers').textContent = datos.followers;
    
    const avatarImg = document.getElementById('github-avatar');
    avatarImg.src = datos.avatar_url;
    avatarImg.style.display = 'inline-block';

  } catch (error) {
    console.error('Error al cargar la API:', error);
    document.getElementById('github-repos').textContent = 'Error al cargar';
  }
}

document.addEventListener('DOMContentLoaded', cargarDatosGitHub);


PASO 3: Subir los cambios a GitHub con Git
--------------------------------------------------------------------------------
Abre tu terminal en la carpeta del proyecto y ejecuta:

git add .
git commit -m "Agregar conexion con API de GitHub en vivo"
git push origin main
